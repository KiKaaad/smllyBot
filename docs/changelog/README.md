## v0.7.0 — Модуль мутов

<div data-with-frame="true"><figure><img src=".gitbook/assets/v0.7.0.gif" alt=""><figcaption><p>Как включить ранний доступ. Как работают мут и мутлист</p></figcaption></figure></div>

### ✨ Новое

* Звездность теперь действительно уменьшается каждые 5 дней на 1%
* Новая команда раннего доступа - `рд`. Позволяет использовать то,\
  что еще не вышло в релиз
* Муты и размуты! Теперь можно мутить сроком до 28 дней, через тайм-ауты\
  (НЕ управляемая роль пока что). Подробнее в `хелп`
* История мутов - `мутлист`

{% hint style="info" %}
Муты, размуты и мутлист будут работать только при включенном режиме тестирования — `рд`
{% endhint %}

* Единый обработчик ошибок. Теперь большинство ответов выглядят более\
  стилизованно под бота
* **Тестировщик:** Можно вызывать ошибки через `debug error`
  * Типы ошибок: `noAccessPermission`,\
    `userNotFound`, `notNumber`, `undefined` и другие

### 🔄️ Обновлено

* Топы стали более отзывчивыми
* Добавлены пагинации в помощь по боту - `хелп`
* UI мешка переписан на Kotlin

### 🐛 Исправлено

* Таблица гильдий могла не создаться из-за неверного типа колонки
* В информации о гильдии (`гильдия`) не выводились часть полей
{% endupdate %}

## v0.6.2 — Гильдии

### ✨ Новое

* Команда `гильдия` - выводит информацию о сервере. Рядом с названием отображается уровень буста в виде эмоджи,\
  описание сервера, количество участников, бустеров, каналов и ролей, айди гильдии, владелец и другое

### 🔄️ Обновлено

* По умолчанию вместо "100 фактов о фембоях" теперь выводится версия бота
* Красивое форматирование чисел в статистике анкеты и профиля: 1234567 → 1.234.567
* Команде профиля добавлен алиас `кто ты`

### 🐛 Исправлено

* При использовании команды `о себе` или `девиз` при переходе обратно исчезал баннер
* При использовании команды `кто я` "я" принималась как аргумент и бот естественно выводил, что такого пользователя нет
* При использовании команды `статбот`, если у бота отсутствовал баннер или аватарка статистика бота просто не выводилась
* В терминал могла выводиться пустота, если любая команда используется без аргументов
{% endupdate %}

## v0.6.0 — Пользовательские команды

### ✨ Новое

* Во много раз более информативная команда - `хелп`. Теперь все распределено на категории с кнопками и при нажатии на кнопку открывается расширенная информации о категории
* Профили, теперь вы можете просмотреть локальный профиль в гильдии - `профиль`
  * Теперь в профиле отображается статистика с гильдии (количество сообщений)
  * Теперь в профиле отображается время самого первого появления в гильдии (а то дискорд гад, сбрасывает время после выхода с гильдии)
* Новая команда - `о себе`
  * Установить о себе - `+о себе` <- Со следующей строки ваше "о себе" | Удалить о себе - `-о себе`
  * Посмотреть текущий установленный "о себе" - `о себе`
* Новая команда - `гражданство`
  * Установить гражданство - `+гражданство` | Удалить гражданство - `-гражданство`
  * Посмотреть текущее гражданство - `гражданство`
* Новая команда - `приватность`
* Теперь можно зарабатывать репутацию путем получения реакций на свои сообщения
* Теперь все настройки можно изменять в файле `config.toml`, а не в неудобном .env
  * Из недавно добавленного:
    * Возможность изменить все параметры экономики
    * Возможность изменить тип кэширования пользователей
* Множество рп-команд
  * `обнять`, `убить`, `осеменить`, `выебать`, `сжечь` и т. д...
  * Также команды поддерживают текст после и реплики
  * обнять очень сильно
  * обнять -> ну ты и этот самый этот вот <- со следующей строки
* Полностью переписанные топы. Теперь при нажатии на кнопку посередине выводится модалка в которой можно сразу переместиться к нужной странице. Также количество строк который этот код занимает около 180, когда прошлый был около 400\
  И мнооожество всего крутого

### 🔄️ Изменено

* Логгер теперь еще более красивенький и удобненький
* Теперь вместо локальный эмоджи бота используются обыкновенные эмоджи
  * _**TODO:** Позже будет что-то типо `emoji.toml` где будет ключ = значение (`emoji_online = <meow:1234>`)_

### 🐛 Исправления

* Профиль мог не выводится, если у пользователя совсем отсутствует гражданство (null)
* При использовании команды `ферма` за раз могло выводится сразу 2 плейсхолдера, если выпадало более 150 и менее 500 ирис-коинов

### ⚙️ Внутренние изменения

* Регистрация модалок и кнопок происходит отдельно от команд. Из-за этого теперь не требуется указывать в алиасах начальный префикс кнопки
  * Дефолтный вид кнопки выглядит как `command:subCommand:discordUserId` (`profile:back:1234567890`)
* Теперь в переопределенном методе `execute` от `BaseCmd` выдается сразу 2 вида сообщения. Raw - не обработанное и Args - разделенное на аргументы по `\\s+`
* Теперь возможна регистрация команд имеющих пробелы, \
  по типу `о себе`
{% endupdate %}
