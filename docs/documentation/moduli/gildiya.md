# Гильдия

`гильдия` — показывает информацию о гильдии

* Количество ролей, каналов и пользователей в гильдии
* Айди гильдии, когда она была создана и ее возраст
* Уровень бустов

`рд` — включить режим раннего доступа.\
Ранний доступ позволяет получить самые новые фишки бота и обычно вместе с ней же выводится информация что станет доступна.\
Функции в раннем доступе помечены значком 🅱️ в [помощи по боту](#user-content-fn-1)[^1].&#x20;

{% hint style="warning" %}
Функции бота, находящиеся в раннем доступе КРАЙНЕ НЕ стабильны. Они могут очень часто изменяться, иметь серьезные баги или уязвимости.&#x20;

Включать их стоит на свой страх и риск, а сообщать об ошибках стоит в [issues](https://github.com/KiKaaad/smllyBot/issues) на GitHub
{% endhint %}

[^1]: `хелп` — выводит категории команд бота
