# Модерация

### ℹ️ Общая структура

По умолчанию все имеют бесконечный срок наказания, если срок не был указан

Тип поддерживает все виды **склонения:** 1 час, 2 часа, 5 часов\
Тип также поддерживает **сокращенные** виды:

* Минуты — мин
* Дни — д
* Часы — ч

### 🔇 Муты

<div data-with-frame="true"><figure><img src="../.gitbook/assets/mutemoder.gif" alt=""><figcaption><p>Мут и размут пользователя</p></figcaption></figure></div>

Муты поддерживают множество возможных вариаций замутить пользователя:

* Ответом на сообщение нарушителя
* С указанием айди нарушителя
* С указанием юзернейма
* С указанием никнейма

{% hint style="warning" %}
Мут через никнейм сработает только в случае, когда пользователь есть в гильдии
{% endhint %}

`мут` <юзернейм / никнейм / айди> <период> <тип> <причина>⬇️[^1] — мутит пользователя

* Период — время, на которое пользователь будет замучен
* Тип — тип времени, который будет использовать для мута
  * Поддерживаются: Секунды, минуты, часы, дни, недели, месяца, года
* _Алиасы: `мьют`, `mute`_

`размут` <юзернейм / никнейм / айди> — размучивает пользователя

* _Алиасы: `unmute`, `размьют`_

**Пример команды:**

```
мут 683345722611073059 12 часов
балбесик
```

### 🔴 Баны

`бан` <юзернейм / никнейм / айди> <период> <тип> <причина>⬇️[^1] — блокирует пользователя

* _Алиасы: `ban`_

`разбан` <юзернейм / никнейм / айди> — разблокирует пользователя

* _Алаисы: `unban`_

Пример команды:

```
бан kikaaad
no good boy
```

[^1]: Причина пишется со следующей строки (Shift + Enter)
