# Экономика

* `ферма` — позволяет фармить ирис-коины раз в 4 часа.\
  Если не использовать команду сразу копится множитель в течении 24 часов. Максимальный множитель — х3
  * _Алиасы: `фарма`, `фарм`, `farm`, `ferma`_
* `мешок` <юзернейм / никнейм / айди> — позволяет увидеть мешок пользователя: Количество ирисок 🍬, ирис-коинов ☢️ и звездность ⭐&#x20;
