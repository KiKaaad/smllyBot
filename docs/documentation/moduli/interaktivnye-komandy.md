# Интерактивные команды

* `рп-команда` <действие> <реплика>⬇️[^1] — в ответ на сообщение пользователя

#### 13+ команды

* `обнять`, `погладить`, `убить`, `сжечь`, `ударить`, `поцеловать`, `шлепнуть`, `выстрелить`, `прижать`, `пнуть`, `взять за руку`, `укусить`, `связать`, `офурить`, `дать пять`, `потискать`, `лизнуть`

#### 18+ команды

* `выебать`, `трахнуть`, `осеменить`, `отсосать`, `отшлепать`, `уебать`



[^1]: Реплика пишется со следующей строки (shift + enter)
