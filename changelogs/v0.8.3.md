# 0.8.3-beta (15.11.2026)
## ✨ Новое
- Команда `мои баны` - позволяет увидеть историю своих банов
- Команда `мои муты` - позволяет увидеть историю своих мутов
- Команда `установить префиксы` - позволяет установить кастомные префиксы для бота
- Теперь при первом входе бот не оставляет вас наедине с мыслями, а кидает помощь при первой установке
- Теперь, если пользователя банят, ему в личные сообщения отправляется сообщение об этом
- Добавлена возможность использовать команды через тег бота вместо префикса

## 🐛 Исправлено
- Часть команд неверно работали с тегом бота в качестве префикса (в частности бан, анкета, профиль)
- Пагинации в команде `мои муты` не работали из-за неверных айди

## ⚙️ Внутренние изменения
- Таблицы в базе данных создаются с помощью миграций, а не внутри кода
- Добавлена таблица warn для будущего модуля
