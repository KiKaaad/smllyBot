# 0.8.1-beta (20.10.2026)
## ✨ Новое
- Бейджики - позволяют выделяться среди остальных пользователей
- Баны: Теперь можно блокировать пользователей даже если их нет в гильдии >w<
## 🐛 Исправлено
- Банлист мог не отображаться, если внутри него была бессрочная блокировка
- Авторазбаны НЕ работали т. к не был запущен планировщик
- Разбаны НЕ работали т. к бот пытался найти участника гильдии, вместо юзера (участника банально нет, т. к его удалили с гильдии)
- Фактически проверки на взаимодействие с кнопками не было, бот просто отдавал что кнопка недоступна
- Менеджер команд не мог обрабатывать бессрочные баны с причиной т. к поиск команды осуществлялся по пробелу, а не по "\n"
- При просмотре владельцем гильдии профиля какого-либо пользователя, этот пользователь выводился как владелец гильдии, т. к доставался не таргет пользователя, а автор сообщения
- Бан мог быть вечным, если вместо срока и типа времени писали гадости, хотя бот мог выдать ошибку
## ⚙️ Внутренние изменения
- Бот разделен на два модуля: discord и telegram. В планах на будущее сделать бота, который одинаково бы работал в обоих API
